# The Security Architect Playbook (SC-100)

A documentation-first portfolio covering the Microsoft SC-100: Cybersecurity Architect Expert exam domains — companion repo to [Zero-to-SOC (SC-200)].

## Why this repo exists
SC-100 tests architecture-level thinking, not hands-on lab execution. This repo captures strategy documents, decision frameworks, and scenario-based case studies across all four exam domains.

## Exam Domain Coverage

| Folder | Domain | Exam Weight |
|---|---|---|
| `01-zero-trust-strategy/` | Design a Zero Trust strategy and architecture | ~30% |
| `02-security-operations-strategy/` | Evaluate Governance Risk Compliance (GRC) strategies | ~20% |
| `03-identity-security-strategy/` | Design security strategy for identity | included in Zero Trust pillar |
| `04-data-apps-infra-strategy/` | Evaluate security posture & recommend technical strategies for infrastructure | ~30% |
| `05-governance-risk-compliance/` | Design a strategy for data, applications, and infrastructure | ~20% |
| `case-studies/` | End-to-end scenario-based architecture decisions | cross-cutting |
